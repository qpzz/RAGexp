# RAG 2026 文献调研 Phase C：阶段摘要

完成日期：2026-10-14。本阶段只回答八类子方向“在解决什么问题、使用什么路线”，不判断新颖性，不寻找研究空白，不提出方法，也未复现实验或调用付费模型。

## 完成范围

对 Phase A/B 的 83 篇候选和 61 篇核心记录完成主分类及去重审计。61 篇均有唯一主分类；A—H 合计 54，另有 M 多模态 4、I 检索表示与索引 1、L 多语言 1、X 系统效率 1。按预设配额从已有核心池选出 **27 篇**：A3、B4、C4、D3、E3、F4、G2、H4，未为凑配额加入池外论文。

27 篇均取得可阅读的本地 PDF，并核对首页标题与来源；其中 PMLR 论文的可读副本部分取自同题 arXiv，WWW FlowRAG 和 SIGIR CoRM-RAG 使用作者版。**正式发表核验**与**全文版本**分开记录：CoRM-RAG 的 DOI 和机构/作者记录可核，但未取得出版社正式全文；对该文具体表格的结论应复核版本差异。个别 PDF 的多栏表格、公式或旋转文本自动提取不完整；本轮只写入能从摘要、正文、图注或表中核实的内容，未确认数值留作 UNKNOWN。

## 八类技术路线概览

|类别|代表论文|本轮可确认的主要路线|
|---|---|---|
|A 文档分块与结构建模|HiChunk、SmartChunk、Ψ-RAG|层级分块评测与 Auto-Merge；查询自适应块粒度；跨文档语料级抽象树。|
|B 自适应检索与查询处理|R3AG、GRIP、DeepRAG、查询改写偏差研究|检索器效用路由；控制 token 触发检索；逐子问题按需检索；改写偏差的受控测量。|
|C 重排序与证据选择|RRPO、BAR-RAG、NEST、CoRM-RAG|生成回报重排；难度边界证据选择；先召回后筛选；反事实偏差稳健重排/弃答。|
|D 上下文压缩与证据融合|SARA、AED-RAG、CORE-RAG|文本＋软向量混合；逐 token 多源融合；任务表现驱动的文本压缩。|
|E 多跳检索与 GraphRAG|ParallaxRAG、T2RAG、State-Aware RAG|多视角 KG 表示；无图三元组填槽；动态工作记忆管理搜索状态。|
|F 知识冲突与证据忠实性|GUARANTRAG、GroupQA、Knowledgeable-R1、RAGLens|双流解码；证据组行为诊断；参数知识/上下文切换训练；内部特征幻觉检测。|
|G 动态知识与反馈适应|ERM、WWW FlowRAG|用验证反馈更新检索 key；参数高效地持续训练检索器。仅两篇，不能推断领域主流。|
|H RAG 评测与鲁棒性|RAG in the Wild、RAGEC、T2-RAGBench、UDCG|多源压力测试；流水线错误归因；未知上下文文本表格基准；面向生成效用的检索指标。|

详细问题、与前人差异、实际数据集/指标/基线、主要实验结论及作者局限均附逐篇页码，见 `paper_reading_cards.md`；跨论文对比见 `technical_route_comparison.md`。这些路线不能直接互相比排名：部分论文优化检索召回，部分研究推理控制、生成忠实性或评价指标，且数据和评价口径不同。

## 文件与继续阅读入口

- `selected_papers.csv`：27 篇的来源、正式发表状态、实际 PDF 版本和页数；UTF-8 BOM。
- `paper_reading_cards.md`：27 份首轮阅读卡，每项均附 PDF 页码、节、图或表及全文链接；未确认字段保留 UNKNOWN。
- `technical_route_comparison.md`：八类问题、路线差异、常用实验设置和重复研究问题；单篇观察已单独限定。
- `datasets_metrics_baselines.csv`：可筛选比较矩阵；UTF-8 BOM。
- `classification_audit.md`：61 篇分类/去重、54＋7 和 2026 正式发表核验。
- 本文件：阶段结论与证据边界。

本阶段到此暂停。下一轮可由读者选择 A—H 中希望深入精读的方向，并指定是否重点核算算法、实验可靠性或复现成本；在选择前不作创新点或新方法推导。
